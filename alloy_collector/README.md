# Home Assistant App: Alloy Collector

Sends Home Assistant's logs and metrics to Loki and Prometheus, using [Grafana Alloy](https://grafana.com/docs/alloy/latest/).

- The host journal: Home Assistant, the Supervisor, every add-on and the OS
- Host metrics of the Home Assistant machine
- CPU, memory, network and disk usage per add-on

See the **Documentation** tab for options and labels.
